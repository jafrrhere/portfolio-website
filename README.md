# Portfolio Website

A modern, responsive portfolio website featuring a terminal-style interface and interactive elements.

## Features

- Terminal-style interface with typing animations
- Responsive design
- Interactive profile card
- Project showcase
- Modern UI with smooth animations

## Setup

1. Clone the repository
2. Open `index.html` in your browser
3. That's it! No additional setup required.

## File Structure

- `index.html` - Main HTML file
- `styles.css` - CSS styles
- `images/` - Image assets

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Customization

To customize the website:

1. Edit `index.html` to update content
2. Modify `styles.css` to change styling
3. Add your own images to the `images/` directory
